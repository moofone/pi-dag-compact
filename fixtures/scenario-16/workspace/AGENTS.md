# Fixture workspace

Use `node bench.mjs run --candidate <id> --workload W1` for measurements.
Do not invent numbers. Cite run IDs. Pipeline p50 is the objective.
A faster kernel with a slower pipeline is not an accepted baseline.
A correctness failure is never an accepted baseline.
A confounded measurement is inconclusive.
Write `notes/state.json` when the baseline, ceiling, or rejections change.
